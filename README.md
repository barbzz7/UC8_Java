# UC8 – Java

Repositório com exercícios e exemplos em **Java** referentes à Unidade Curricular 8 (**UC8**), focado em prática de programação orientada a objetos, estruturas de controle e manipulação de dados.

Este projeto contém diversos arquivos com exemplos implementados em Java para reforçar conceitos aprendidos em aula.

## 📌 O que Você Vai Encontrar

### 📍 Exercícios com Scanner

Exercícios que recebem input do usuário pelo terminal e processam dados, como:

- leitura de números e strings
- cálculos simples
- decisões com `if/else` e `switch`

---

### ⚙️ Programação Orientada a Objetos

Implementação de conceitos de:

- **Classes e Objetos**
- **Encapsulamento**
- **Herança**
- **Métodos**
- **Construtores**

Exemplo de classes:

- `ContaBancaria` — representa uma conta com depósito e saque
- `Cliente` — classe que guarda informações do cliente
- Outras classes de apoio
